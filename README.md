# 电网继电保护定值配合与故障场景审校平台

面向电网继电保护工程师的本地审校工作台。项目使用 Vue 3、Element Plus、Pinia、Vue Router、TanStack Query、Axios 和 Vite 构建，并用原生 Canvas 绘制保护配合曲线。

## 功能

- 维护线路、变压器、母线、断路器和保护装置，编辑各段定值、方向、灵敏度、重合闸和启动条件。
- 批量检查越级跳闸、时限倒挂、灵敏度不足和重合逻辑冲突，问题定位到保护对，支持意见回复和关闭。
- Canvas 配合曲线支持滚轮时间轴缩放和 Shift + 滚轮电流轴缩放，装置依赖图展示上下级关系。
- 建立运行方式和故障场景，对比动作序列与停电范围，执行异常场景逐步回放。
- 创建基线快照、比较当前定值与基线差异、记录会签意见，并在高风险问题闭环后锁定基线。
- 审计设备、定值、校验、场景、基线和导出操作，导出 UTF-8 CSV 定值清单。

### 断网修改与回网审校链

现场断网改定值、回网常与调度端改动撞车，平台把设备台账、保护定值、故障场景、基线版本和审计接成可恢复的审校链：

- **修订号**：设备/定值/场景/基线带实体 `rev` 与全局流水号 `headRev`；旧数据缺修订号时按首次导入统一回填 `rev=1` 并写迁移审计。
- **离线包**：断网瞬间冻结字段基线值与修订号，断网期间按字段累计变更（同一字段只留最新一笔），本地先做校核重算。
- **三方合并**：回网提交时逐字段比对（共同基线 / 现场值 / 调度端值）——调度端未动直接应用，改成同值幂等跳过，两端改过同一字段且不同则**保留两版待复核**。
- **级联重算**：定值一变，校核问题全量重算（保留同问题处理状态），引用变动定值的场景降为“定值已变·待重算”，会签中基线失效、已锁定基线标记漂移。
- **同包去重**：离线包 id 即幂等键，处理窗口内并发重复提交返回 409，只放行第一份；已完整接收的包再次提交同样拒绝。
- **断点续传**：模拟第 N 批写入失败时，前 N-1 批已落库并保留回执游标，恢复时只续传未完成批次。
- **有效版本同源**：审批页（会签与基线）与执行页（定值执行）共用同一个锁定版本；执行前核对校验码，版本漂移或校验码不一致时禁止下装。

“断网合并”页提供完整演示：① 调度端改值制造撞车 → ② 断网现场改同一字段 → ③ 回网提交（含并发提交、写入失败与续传）→ ④ 冲突字段二选一裁定 → ⑤ 查看级联重算结果。

所有业务数据由本地模拟服务提供并通过 `localStorage` 持久化，不依赖后端；调度端权威状态与离线包使用独立存储键。

## 运行

```bash
npm install
npm run dev
```

开发服务地址：`http://localhost:18455`

## 构建与测试

```bash
npm run build       # 类型检查 + 生产构建
npm run preview
npm run test:smoke  # 合并/冲突/续传/级联/回填的纯逻辑断言
```

## 目录

```text
src/
  api/         Axios 本地适配器（含 /sync 合并、裁定、调度端改动模拟）与查询
  components/  页面头、问题表、Canvas 曲线、装置依赖图
  data/        领域模拟数据（旧档案无 rev，首次导入回填）
  router/      多页面路由
  services/    校验规则、差异计算、修订号/校验码、三方合并、级联重算、本地存储
  stores/      Pinia 业务状态（app）与断网协同状态机（sync）
  types/       领域类型（含离线包、字段冲突、合并回执）
  views/       总览、台账、编辑、校核、场景、审批基线、定值执行、断网合并、审计
scripts/
  smoke.ts     审校链核心规则断言（npm run test:smoke）
```
