# 电网继电保护定值配合与故障场景审校平台

面向电网继电保护工程师的本地审校工作台。项目使用 Vue 3、Element Plus、Pinia、Vue Router、TanStack Query、Axios 和 Vite 构建，并用原生 Canvas 绘制保护配合曲线。所有业务数据由本地模拟服务提供并通过 `localStorage` 持久化，不依赖后端。

## 功能

- 维护线路、变压器、母线、断路器和保护装置，编辑各段定值、方向、灵敏度、重合闸和启动条件；设备台账与定值均带**修订号（rev）**，任何来源写入成功即自增。
- 批量检查越级跳闸、时限倒挂、灵敏度不足和重合逻辑冲突，问题定位到保护对，支持意见回复和关闭。
- Canvas 配合曲线支持滚轮时间轴缩放和 Shift + 滚轮电流轴缩放，装置依赖图展示上下级关系。
- 建立运行方式和故障场景，对比动作序列与停电范围，执行异常场景逐步回放。
- 创建基线快照、比较当前定值与基线差异、记录会签意见，并在高风险问题闭环、快照未失效后锁定为**唯一有效版本**。
- 审计设备、定值、校验、场景、基线、离线合并与导出操作，导出 UTF-8 CSV 定值清单（含修订号与有效版本）。

### 断网修改与回网合并（审校链）

- **离线包**：断网期间在现场把若干定值修改封存为离线包，记录共同基底校验码、现场、负责人和固定幂等键。
- **三方合并**：回网提交时按「共同基线 / 现场离线版 / 调度在库版」逐字段合并——调度端未改则快进合并；两端改成相同值自动一致跳过；**两端改过同一字段且取值不同则保留两版生成待复核冲突**，不覆盖任何一方。
- **同包只放行一份**：基于幂等键 + 在途提交锁，同一份包两人（或两个会话）同时提交只放行一份，其余请求返回明确拒绝；已合并包的重复提交一律幂等拦截。
- **写入失败可恢复**：批次逐项落盘并把提交锁标记为 `interrupted`；注入写入失败后，已完成批次保留、剩余项保持待写入，重新提交即断点续传。
- **定值一变即级联失效重算**：合并写入或冲突裁决后校核问题全量重算（保留问题处理状态）；已批准场景按定值校验码自动判失效，需重新验证；会签中基线快照失效需重建后重新会签（已锁定有效版本不被在线修改推翻）。
- **旧数据回填修订号**：旧版本 `localStorage` 数据自动迁移，缺少修订号的设备/定值在首次导入时回填为 rev 1，并写入审计。
- **审批页与执行页同一有效版本**：执行下发页与基线会签页读取同一个已锁定基线（版本号 + 校验码）；当前定值偏离有效版本或存在未闭环高风险问题时禁止下发。

> 断网合并中心提供一键演示链路：生成演示离线包 → 模拟调度端改同一字段（撞车）→ 回网合并（可注入第 2 项写入失败后恢复续传）→ 冲突两版复核 → 级联重算 → 场景/基线重新确认 → 锁定新版本并执行下发。

## 运行

```bash
npm install
npm run dev
```

开发服务地址：`http://localhost:18455`

## 构建

```bash
npm run build
npm run preview
```

## 目录

```text
src/
  api/         Axios 本地适配器（含提交锁、合并批次、调度端改动、旧台账导入）与 TanStack Query
  components/  页面头、问题表、Canvas 曲线、装置依赖图
  data/        领域模拟数据
  router/      多页面路由
  services/    校验规则、修订号/校验码、三方合并引擎、差异计算、本地存储和导出
  stores/      Pinia 业务状态与状态流转
  types/       领域类型（离线包、合并冲突、提交锁、有效版本执行记录）
  views/       总览、台账、编辑、校核、场景、基线、断网合并、有效版本执行、审计
```
